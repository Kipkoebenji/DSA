# Recursion and Backtracking

## Recursion

- Function calling itself
- Base case (stopping condition)
- Recursive case (progress toward base case)

## Backtracking

- Explore all possibilities
- Prune invalid paths early
- Classic brute-force with optimization

## Key Concepts

- Call stack
- Memoization
- Tail recursion

## Common Patterns

- Divide and conquer
- Tree traversal
- Permutations and combinations
- Subset generation
- N-Queens problem
- Sudoku solver

## Time Complexity

- Often exponential: O(2^n), O(n!)
- Can be optimized with memoization
