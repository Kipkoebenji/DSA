# Hashing

## Key Concepts

- Hash function
- Hash table / Hash map
- Collision resolution (chaining, open addressing)
- Load factor

## Time Complexity

- Average case: O(1) for insert, delete, search
- Worst case: O(n) (with many collisions)

## Common Patterns

- Frequency counting
- Two sum / N sum problems
- Duplicate detection
- Caching / memoization
- Anagrams grouping

## JavaScript Data Structures

- `Map` - key-value pairs, any type as key
- `Set` - unique values
- `Object` - string/symbol keys only

## Applications

- Database indexing
- Caching
- Symbol tables
- Password verification
