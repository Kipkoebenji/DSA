# Strings

## Key Concepts

- Immutable in JavaScript (primitive strings)
- Character manipulation
- Pattern matching
- String building techniques

## Time Complexity

- Access: O(1)
- Search: O(n)
- Concatenation: O(n)
- Substring: O(n)

## Common Patterns

- Two pointers
- Sliding window
- String matching (KMP, Rabin-Karp)
- Palindrome checking
- Anagrams

## JavaScript String Methods

- `slice()`, `substring()`, `substr()`
- `split()`, `join()`
- `indexOf()`, `includes()`
- `replace()`, `replaceAll()`
- `toLowerCase()`, `toUpperCase()`
