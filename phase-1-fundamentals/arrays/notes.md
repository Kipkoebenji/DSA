# Arrays

## Key Concepts

- Contiguous memory allocation
- Index-based access (O(1))
- Common operations: insertion, deletion, searching, sorting

## Time Complexity

- Access: O(1)
- Search: O(n)
- Insertion: O(n) (worst case)
- Deletion: O(n) (worst case)

## Common Patterns

- Two pointers
- Sliding window
- Kadane's algorithm
- Prefix sum
