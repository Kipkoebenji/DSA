# Searching and Sorting

## Searching Algorithms

- **Linear Search**: O(n)
- **Binary Search**: O(log n) - requires sorted array
- **Jump Search**: O(√n)
- **Interpolation Search**: O(log log n) average

## Sorting Algorithms

### O(n²) Algorithms

- **Bubble Sort**: Simple, stable
- **Selection Sort**: In-place
- **Insertion Sort**: Good for small/nearly sorted data

### O(n log n) Algorithms

- **Merge Sort**: Stable, divide-and-conquer
- **Quick Sort**: In-place, fastest average case
- **Heap Sort**: In-place, guaranteed O(n log n)

### O(n) Algorithms (special cases)

- **Counting Sort**: For limited range integers
- **Radix Sort**: For integers/strings
- **Bucket Sort**: For uniformly distributed data

## Common Patterns

- Binary search on answer
- Modified binary search
- Two pointers with sorting
