# Data Structures & Algorithms - JavaScript

A comprehensive DSA learning path organized by phases, from fundamentals to competitive programming and real-world projects.

## 📚 Learning Path

### Phase 1: Fundamentals

- [ ] **Arrays** - Basic operations, two pointers, sliding window
- [ ] **Strings** - Pattern matching, manipulation, palindromes
- [ ] **Linked Lists** - Singly/doubly linked lists, cycle detection

### Phase 2: Intermediate

- [ ] **Stacks & Queues** - LIFO/FIFO operations, monotonic structures
- [ ] **Recursion & Backtracking** - Tree problems, permutations, N-Queens
- [ ] **Hashing** - Hash maps, sets, frequency counting

### Phase 3: Advanced Data Structures

- [ ] **Trees** - Binary trees, BST, traversals, LCA
- [ ] **Heaps** - Min/max heaps, priority queues
- [ ] **Graphs** - BFS, DFS, shortest paths, MST

### Phase 4: Core Algorithms

- [ ] **Searching & Sorting** - Binary search, merge/quick sort
- [ ] **Divide & Conquer** - Master theorem, recursive solutions
- [ ] **Dynamic Programming** - Memoization, tabulation, common patterns

### Phase 5: Competitive Programming

- [ ] **Greedy Algorithms** - Activity selection, Huffman coding
- [ ] **Bit Manipulation** - Bitwise operations, XOR tricks
- [ ] **Advanced Topics**
  - [ ] Tries - Prefix trees, autocomplete
  - [ ] Segment Trees - Range queries
  - [ ] Flow Algorithms - Network flow, max flow

### Phase 6: Projects

- [ ] **Pathfinding Visualizer** - A\*, Dijkstra, BFS/DFS visualization
- [ ] **Autocomplete with Tries** - Search suggestions
- [ ] **Mini Search Engine** - Inverted index, TF-IDF ranking

## 📖 Structure

Each topic folder contains:

- `notes.md` - Concepts, patterns, time complexities
- `problems/` - Practice problems (3 per topic)
- `implementations/` - Algorithm implementations (2 per topic)
