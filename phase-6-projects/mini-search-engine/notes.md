# Mini Search Engine

## Project Overview

Build a simple search engine with indexing and ranking capabilities.

## Features

- Document indexing
- Keyword search
- TF-IDF ranking
- Inverted index
- Search result relevance
- Optional: Boolean queries (AND, OR, NOT)

## Technologies

- JavaScript/Node.js
- Hash maps for indexing
- String processing
- Optional: Web scraping

## Learning Goals

- Understand inverted index
- Implement TF-IDF algorithm
- String tokenization and processing
- Ranking algorithms
- Data structure optimization

## Implementation Steps

1. Build inverted index
2. Implement document parsing
3. Calculate TF-IDF scores
4. Implement search function
5. Rank results by relevance
6. Add query processing
7. Build simple UI

## Components

- **Indexer**: Process and index documents
- **Searcher**: Query the index
- **Ranker**: Score and sort results
- **UI**: Display search results
