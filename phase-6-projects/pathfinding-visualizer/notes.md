# Pathfinding Visualizer

## Project Overview

Build a visual tool to demonstrate pathfinding algorithms on a grid.

## Features

- Interactive grid (click to add walls/obstacles)
- Visualization of different algorithms:
  - Dijkstra's Algorithm
  - A\* Search
  - Breadth-First Search (BFS)
  - Depth-First Search (DFS)
- Adjustable grid size
- Speed control for visualization
- Start/end point selection

## Technologies

- HTML5 Canvas or CSS Grid for visualization
- Vanilla JavaScript or React
- CSS for styling

## Learning Goals

- Understand graph traversal algorithms
- Visualize algorithm execution
- DOM manipulation and animation
- Event handling

## Implementation Steps

1. Create grid structure
2. Implement pathfinding algorithms
3. Add visualization/animation
4. Create UI controls
5. Add interactivity (wall placement)
